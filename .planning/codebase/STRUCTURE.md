## Directory Purposes

**`packages/`:**

- Purpose: Main source code for the Bun/TypeScript monorepo.
- Contains: Workspace packages, each with its own `package.json`, `tsconfig.json`, and `src/`.
- Key files: `package.json`, `packages/*/package.json`.

**`packages/cli/`:**

- Purpose: Command-line product surface for running workflows, chat, setup, serve, skill install, validation, isolation, and lifecycle commands.
- Contains: `src/cli.ts`, command modules under `src/commands/`, CLI platform adapter under `src/adapters/`.
- Key files: `packages/cli/src/cli.ts`, `packages/cli/src/commands/workflow.ts`, `packages/cli/src/commands/serve.ts`, `packages/cli/src/commands/skill.ts`.

**`packages/server/`:**

- Purpose: Backend runtime for Web UI, REST API, SSE, webhooks, and platform adapters.
- Contains: Server entrypoint, Hono route modules, web adapter implementation, test helpers, setup-auth script.
- Key files: `packages/server/src/index.ts`, `packages/server/src/routes/api.ts`, `packages/server/src/adapters/web.ts`, `packages/server/src/adapters/web/transport.ts`, `packages/server/src/adapters/web/persistence.ts`, `packages/server/src/adapters/web/workflow-bridge.ts`.

**`packages/web/`:**

- Purpose: Browser UI for conversations, workflow runs, workflow builder, dashboard, and settings.
- Contains: React routes, components, hooks, stores, API client, generated API types.
- Key files: `packages/web/src/App.tsx`, `packages/web/src/main.tsx`, `packages/web/src/lib/api.ts`, `packages/web/src/stores/workflow-store.ts`, `packages/web/vite.config.ts`.

**`packages/core/`:**

- Purpose: Shared product logic for orchestration, persistence, configuration, services, operations, and types.
- Contains: `db/`, `orchestrator/`, `config/`, `handlers/`, `operations/`, `services/`, `state/`, `types/`, `utils/`, `workflows/`.
- Key files: `packages/core/src/orchestrator/orchestrator-agent.ts`, `packages/core/src/orchestrator/orchestrator.ts`, `packages/core/src/db/connection.ts`, `packages/core/src/workflows/store-adapter.ts`, `packages/core/src/config/config-loader.ts`.

**`packages/workflows/`:**

- Purpose: Workflow language and runtime.
- Contains: Zod schemas, YAML loader, workflow discovery, DAG executor, event emitter, command/script validation, bundled defaults.
- Key files: `packages/workflows/src/schemas/workflow.ts`, `packages/workflows/src/schemas/dag-node.ts`, `packages/workflows/src/loader.ts`, `packages/workflows/src/workflow-discovery.ts`, `packages/workflows/src/executor.ts`, `packages/workflows/src/dag-executor.ts`, `packages/workflows/src/event-emitter.ts`.

**`packages/providers/`:**

- Purpose: AI assistant provider abstraction and implementations.
- Contains: Claude, Codex, community Pi provider directories, capabilities, config translators, binary resolvers, registry, shared types.
- Key files: `packages/providers/src/registry.ts`, `packages/providers/src/types.ts`, `packages/providers/src/claude/provider.ts`, `packages/providers/src/codex/provider.ts`, `packages/providers/src/community/pi/registration.ts`.

**`packages/isolation/`:**

- Purpose: Worktree isolation policy, provider implementation, and shared types.
- Contains: Resolver, factory, provider, PR state, worktree copy, errors, store interface.
- Key files: `packages/isolation/src/resolver.ts`, `packages/isolation/src/providers/worktree.ts`, `packages/isolation/src/worktree-copy.ts`, `packages/isolation/src/types.ts`, `packages/isolation/src/store.ts`.

**`packages/git/`:**

- Purpose: Git subprocess and repo/worktree helpers shared by CLI, isolation, core, providers, and workflows.
- Contains: Branch, repo, worktree, exec, GitHub CLI auth helpers.
- Key files: `packages/git/src/exec.ts`, `packages/git/src/repo.ts`, `packages/git/src/branch.ts`, `packages/git/src/worktree.ts`, `packages/git/src/github-cli-auth.ts`.

**`packages/paths/`:**

- Purpose: Shared path, logger, env, bundled-build, and update-check utilities.
- Contains: Archon home/workspace/worktree/artifact path helpers, env stripping/loading, logger, bundled build constants.
- Key files: `packages/paths/src/archon-paths.ts`, `packages/paths/src/env-loader.ts`, `packages/paths/src/strip-cwd-env-boot.ts`, `packages/paths/src/logger.ts`.

**`packages/adapters/`:**

- Purpose: Platform adapters outside the server package.
- Contains: Telegram, Discord, Slack, GitHub, Gitea, GitLab, message splitting helpers.
- Key files: `packages/adapters/src/chat/telegram/adapter.ts`, `packages/adapters/src/chat/slack/adapter.ts`, `packages/adapters/src/forge/github/adapter.ts`, `packages/adapters/src/community/forge/gitea/adapter.ts`, `packages/adapters/src/community/forge/gitlab/adapter.ts`.

**`packages/docs-web/`:**

- Purpose: Documentation website.
- Contains: Astro/Starlight config, docs content, assets, custom CSS.
- Key files: `packages/docs-web/src/content.config.ts`, `packages/docs-web/src/content/docs/index.mdx`.

**`.archon/`:**

- Purpose: Repo-local Archon runtime assets.
- Contains: Workflows, command prompt files, scripts, maintainer standup assets, config.
- Key files: `.archon/config.yaml`, `.archon/workflows/defaults/`, `.archon/workflows/test-workflows/`, `.archon/commands/defaults/`, `.archon/scripts/`.

**`.agents/skills/`:**

- Purpose: Repo-local skills for Archon use, development, validation, release, sync, and operator workflows.
- Contains: `SKILL.md` files plus references, guides, agents, scripts, hooks where needed.
- Key files: `.agents/skills/archon/SKILL.md`, `.agents/skills/archon-dev/SKILL.md`, `.agents/skills/my-achrchon-sync/SKILL.md`, `.agents/skills/validate-ui/SKILL.md`.

**`.codex/skills/`:**

- Purpose: Repo-local GSD command skills for Codex.
- Contains: One skill directory per GSD command; each `SKILL.md` points at `.codex/get-shit-done/workflows/`.
- Key files: `.codex/skills/gsd-map-codebase/SKILL.md`, `.codex/skills/gsd-plan-phase/SKILL.md`, `.codex/skills/gsd-execute-phase/SKILL.md`.

**`.codex/get-shit-done/`:**

- Purpose: Embedded GSD workflow definitions, templates, references, and binaries.
- Contains: `workflows/`, `templates/`, `references/`, `contexts/`, `bin/`.
- Key files: `.codex/get-shit-done/templates/codebase/architecture.md`, `.codex/get-shit-done/templates/codebase/structure.md`.

**`.claude/`:**

- Purpose: Claude-facing commands, skills, agents, rules, and PRP artifacts.
- Contains: `skills/`, `commands/`, `agents/`, `rules/`, `PRPs/`, `archon/`.
- Key files: `.claude/skills/archon/SKILL.md`, `.claude/commands/`, `.claude/rules/`.

**`docs/`:**

- Purpose: Human and agent-facing planning/reference documents.
- Contains: `design/`, `prd/`, `plans/`, `reference/`.
- Key files: `docs/reference/mase-archon-fork-operating-model.md`, `docs/design/codex-piv-v2-workflow-design.md`, `docs/prd/r001-archon-piv-loop-codex-v2.md`, `docs/plans/`.

**`migrations/`:**

- Purpose: SQL schema evolution for Archon state.
- Contains: Numbered SQL migrations and `000_combined.sql`.
- Key files: `migrations/000_combined.sql`, `migrations/020_codebase_env_vars.sql`, `migrations/021_add_allow_env_keys_to_codebases.sql`.

**`auth-service/`:**

- Purpose: Separate cookie-based auth sidecar for Caddy `forward_auth`.
- Contains: Node server, test script, Dockerfile, package manifest.
- Key files: `auth-service/server.js`, `auth-service/test.js`, `auth-service/package.json`, `auth-service/Dockerfile`.

**`scripts/`:**

- Purpose: Repository scripts for builds, bundled defaults, E2E checks, and release support.
- Contains: TypeScript scripts and shell scripts.
- Key files: `scripts/generate-bundled-defaults.ts`, `scripts/build-binaries.sh`, `scripts/e2e/`.

## Key File Locations

**Entry Points:**

- `packages/cli/src/cli.ts`: Main `archon` CLI.
- `packages/server/src/index.ts`: Server process and platform adapter boot.
- `packages/web/src/main.tsx`: React app mount.
- `packages/web/src/App.tsx`: Browser routes and global providers.
- `auth-service/server.js`: Auth sidecar server.

**Configuration:**

- `package.json`: Root workspace, scripts, Bun engine, root dependencies.
- `tsconfig.json`: Root TypeScript configuration.
- `packages/*/package.json`: Package-specific dependencies, exports, scripts.
- `.archon/config.yaml`: Repo-local Archon config.
- `packages/core/src/config/config-loader.ts`: Global/repo/env config merge.
- `packages/paths/src/env-loader.ts`: Archon-owned env loading.
- `packages/paths/src/strip-cwd-env-boot.ts`: Entry-point CWD env stripping.
- `docker-compose.yml`, `deploy/docker-compose.yml`: Compose stacks.

**Core Logic:**

- `packages/core/src/orchestrator/orchestrator-agent.ts`: Message routing and AI orchestration.
- `packages/core/src/orchestrator/orchestrator.ts`: Isolation bridge and background workflow dispatch.
- `packages/workflows/src/executor.ts`: Workflow run lifecycle.
- `packages/workflows/src/dag-executor.ts`: DAG node execution.
- `packages/workflows/src/loader.ts`: Workflow YAML parsing and validation.
- `packages/workflows/src/schemas/`: Workflow, node, hook, Codex option schemas.
- `packages/providers/src/registry.ts`: Provider registry.
- `packages/isolation/src/resolver.ts`: Isolation resolution policy.
- `packages/isolation/src/providers/worktree.ts`: Worktree creation/removal.

**REST and Web UI:**

- `packages/server/src/routes/api.ts`: REST, OpenAPI, SSE, workflow run, artifact, codebase, conversation, config endpoints.
- `packages/server/src/routes/schemas/`: API schemas.
- `packages/web/src/lib/api.ts`: Web API client.
- `packages/web/src/routes/`: Top-level pages.
- `packages/web/src/components/`: UI components grouped by feature.
- `packages/web/src/hooks/`: React hooks.
- `packages/web/src/stores/`: Zustand stores.

**Persistence:**

- `packages/core/src/db/connection.ts`: DB selection and singleton.
- `packages/core/src/db/codebases.ts`: Codebase rows.
- `packages/core/src/db/conversations.ts`: Conversation rows.
- `packages/core/src/db/messages.ts`: Message rows.
- `packages/core/src/db/sessions.ts`: Assistant session rows.
- `packages/core/src/db/workflows.ts`: Workflow run rows.
- `packages/core/src/db/workflow-events.ts`: Workflow event rows.
- `packages/core/src/db/isolation-environments.ts`: Worktree/isolation rows.
- `packages/core/src/db/env-vars.ts`: Codebase-scoped env vars.
- `migrations/000_combined.sql`: Combined schema.

**Testing:**

- Co-located test files use `*.test.ts` and `*.test.tsx` across `packages/*/src/`.
- Package scripts in `packages/*/package.json` define package-specific Bun test commands.
- Root `package.json` defines `bun --filter '*' --parallel test`.

**Generated or Derived Outputs:**

- `packages/workflows/src/defaults/bundled-defaults.generated.ts`: Generated bundled workflow/command defaults.
- `packages/web/src/lib/api.generated.d.ts`: Generated OpenAPI types.
- `artifacts/`, `graphify-out/`, `test-results/`: Derived local outputs.

## Naming Conventions

**Files:**

- TypeScript implementation files use kebab-case or domain nouns: `workflow-discovery.ts`, `command-handler.ts`, `config-loader.ts`, `orchestrator-agent.ts`.
- React components use PascalCase: `ChatPage.tsx`, `DashboardPage.tsx`, `WorkflowBuilder.tsx`.
- Tests are co-located with `.test.ts` or `.test.tsx`: `packages/workflows/src/executor.test.ts`, `packages/web/src/lib/format.test.ts`.
- API schema files use feature names plus `.schemas.ts`: `packages/server/src/routes/schemas/workflow.schemas.ts`.
- SQL migrations use numeric prefixes: `migrations/020_codebase_env_vars.sql`.
- Skill entry files are named `SKILL.md`.

**Directories:**

- Workspace packages use domain names under `packages/`: `core`, `workflows`, `providers`, `isolation`.
- Frontend feature directories group by surface: `packages/web/src/components/chat`, `packages/web/src/components/workflows`, `packages/web/src/routes`.
- Workflow/command defaults live under `.archon/workflows/defaults/` and `.archon/commands/defaults/`.
- GSD generated maps live under `.planning/codebase/`.

## Where to Add New Code

**New CLI Command:**

- Primary code: `packages/cli/src/commands/<name>.ts`
- Dispatch wiring: `packages/cli/src/cli.ts`
- Tests: `packages/cli/src/commands/<name>.test.ts`
- Use existing command shape from `packages/cli/src/commands/workflow.ts` or `packages/cli/src/commands/serve.ts`.

**New Server API Endpoint:**

- Route and handler: `packages/server/src/routes/api.ts`
- Request/response schema: `packages/server/src/routes/schemas/<feature>.schemas.ts`
- Tests: `packages/server/src/routes/api.<feature>.test.ts`
- Client call: `packages/web/src/lib/api.ts`
- Generated client types: `packages/web/src/lib/api.generated.d.ts` after OpenAPI generation.

**New Web Page:**

- Route component: `packages/web/src/routes/<FeaturePage>.tsx`
- Router wiring: `packages/web/src/App.tsx`
- Components: `packages/web/src/components/<feature>/`
- Hooks: `packages/web/src/hooks/`
- Feature state: `packages/web/src/stores/` only when shared or complex.

**New Web Component:**

- Implementation: `packages/web/src/components/<feature>/<Component>.tsx`
- Shared primitives: `packages/web/src/components/ui/`
- Avoid route-level business logic in shared UI primitives.

**New Workflow Engine Behavior:**

- Schema changes: `packages/workflows/src/schemas/`
- Parse/validation changes: `packages/workflows/src/loader.ts` or `packages/workflows/src/validator.ts`
- Runtime changes: `packages/workflows/src/executor.ts`, `packages/workflows/src/dag-executor.ts`, or `packages/workflows/src/executor-shared.ts`
- Tests: matching co-located `*.test.ts` under `packages/workflows/src/`.

**New Workflow Definition:**

- Project-local workflow: `.archon/workflows/<name>.yaml`
- Bundled/default workflow source: `.archon/workflows/defaults/<name>.yaml`
- Regenerate/check bundled defaults with root `generate:bundled` or `check:bundled` scripts from `package.json`.
- Use command prompts from `.archon/commands/` or `.archon/commands/defaults/`.

**New Command Prompt:**

- Project-local command: `.archon/commands/<name>.md`
- Bundled/default command: `.archon/commands/defaults/<name>.md`
- Validate names with workflow command validation rules in `packages/workflows/src/command-validation.ts`.

**New AI Provider:**

- Implementation: `packages/providers/src/community/<id>/`
- Registration: `packages/providers/src/registry.ts`
- Capabilities: `packages/providers/src/community/<id>/capabilities.ts`
- Config parsing/translation: `packages/providers/src/community/<id>/`
- Tests: `packages/providers/src/community/<id>/*.test.ts`
- Keep shared provider type definitions in `packages/providers/src/types.ts` free of SDK imports.

**New Platform Adapter:**

- Shared adapter implementation: `packages/adapters/src/chat/<platform>/` or `packages/adapters/src/forge/<platform>/`
- Server startup wiring: `packages/server/src/index.ts`
- Interface contract: `packages/core/src/types/index.ts`
- Tests: co-located under `packages/adapters/src/`.

**New Isolation Behavior:**

- Policy/resolution: `packages/isolation/src/resolver.ts`
- Worktree mechanism: `packages/isolation/src/providers/worktree.ts`
- Copy-file rules: `packages/isolation/src/worktree-copy.ts`
- DB backing: `packages/core/src/db/isolation-environments.ts`
- CLI/API operations: `packages/core/src/operations/isolation-operations.ts`, `packages/cli/src/commands/isolation.ts`.

**New Database Table or Column:**

- Migration: `migrations/<number>_<description>.sql`
- Combined schema update: `migrations/000_combined.sql`
- DB module: `packages/core/src/db/<domain>.ts`
- Types: `packages/core/src/types/index.ts` or package-local schema/types.
- Tests: `packages/core/src/db/<domain>.test.ts`.

**New Configuration Option:**

- Types: `packages/core/src/config/config-types.ts`
- Loader/merge/safe output: `packages/core/src/config/config-loader.ts`
- Path utility if path-related: `packages/paths/src/archon-paths.ts`
- Web settings schema/API if user-visible: `packages/server/src/routes/schemas/config.schemas.ts`, `packages/server/src/routes/api.ts`, `packages/web/src/routes/SettingsPage.tsx`.

**New Repo-Local Skill:**

- Skill directory: `.agents/skills/<skill-name>/` for Archon/operator skills or `.codex/skills/<skill-name>/` for GSD/Codex command skills.
- Entry file: `.agents/skills/<skill-name>/SKILL.md` or `.codex/skills/<skill-name>/SKILL.md`.
- References/guides/scripts: subdirectories under the skill directory.
- For host skill, bundled skill install, or global skill sync changes, read `docs/reference/mase-archon-fork-operating-model.md` first.

**Utilities:**

- Shared core utilities: `packages/core/src/utils/`
- Git utilities: `packages/git/src/`
- Path/env/logger utilities: `packages/paths/src/`
- Workflow utilities: `packages/workflows/src/utils/`
- Web utilities: `packages/web/src/lib/`.

## Special Directories

**`.planning/`:**

- Purpose: GSD project state, codebase maps, planning artifacts.
- Generated: Yes
- Committed: Project-dependent; mapping docs are intended as durable planning references.

**`.agents/skills/`:**

- Purpose: Repo-local skills and fork-specific operator procedures.
- Generated: No
- Committed: Yes

**`.codex/skills/`:**

- Purpose: Repo-local Codex/GSD command skills.
- Generated: Partly installed/scaffolded, then maintained as source.
- Committed: Yes

**`.codex/get-shit-done/`:**

- Purpose: Local GSD workflow system assets consumed by `.codex/skills/`.
- Generated: Installed/copied workflow system assets.
- Committed: Yes in this fork.

**`.archon/workflows/defaults/` and `.archon/commands/defaults/`:**

- Purpose: Bundled default workflows and commands for Archon runtime.
- Generated: Source defaults are maintained here; generated bundle output lives in `packages/workflows/src/defaults/bundled-defaults.generated.ts`.
- Committed: Yes

**`.worktrees/`:**

- Purpose: Local git worktrees for isolated workflow runs.
- Generated: Yes
- Committed: No

**`artifacts/`:**

- Purpose: Local workflow, PRD, validation, and campaign artifacts.
- Generated: Yes
- Committed: Depends on artifact class; inspect before editing.

**`graphify-out/`:**

- Purpose: Derived graph/cache output.
- Generated: Yes
- Committed: Derived evidence; treat as regenerated output unless specifically scoped.

**`node_modules/`:**

- Purpose: Installed dependencies.
- Generated: Yes
- Committed: No

**`test-results/`:**

- Purpose: Test output artifacts.
- Generated: Yes
- Committed: No

**`homebrew/`:**

- Purpose: Packaging files for Homebrew release flows.
- Generated: No
- Committed: Yes
